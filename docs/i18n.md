# 中英西三语界面

右上角的原生语言选择器支持中文、English、Español，默认中文。页面无需刷新即可切换；同一浏览器、同一站点记住上次选择。若浏览器禁止本地存储，本次切换仍然可用。HTML 的 `lang` 与页面标题同步更新，已用时间按语言格式显示。

## 切换范围

覆盖页面、上传说明、六阶段／人工三阶段进度、模型健康状态、组件列表与类别、照片覆盖层、三维操作、错误回退、下载按钮和处理说明。已知本地 API 错误与模型警告在显示时翻译；未收录的诊断原文保留，以免猜测错误含义。

V2 新增的单／多设备范围、边界细化草稿、正负点、撤销／清空／重框、确认／仅框保存与相关错误均有中英西译文。切换保留待确认草稿、提示点与正在运行的细化，不提交新请求。

切换不会重新提交识别，也不卸载工作台或三维查看器；当前照片、任务、相机、选择、隐藏、分解程度和未提交的组件修改保持。刷新页面会恢复语言选择；当前原型不在刷新后自动恢复整个任务工作区。

V3 的照片组、逐视角进度、点大小／背景、全局组件关联与拆开、几何复用提示和质量警告均补齐三语；两个模式切换不重挂载已打开工作区。

## 组件名称与数据

系统自带的 `主机外壳`、`安装支架`、`支撑立柱`、`线缆束` 等名称仅在界面显示时翻译。名称的来源与当前组件类别分开记录，因此只改类别不会让名称突然换回中文。显式编辑的名称视为用户输入，即使内容与系统默认名相同，也在后续人工重建与语言切换中保留原文。

本地 `labelEdited` 只记录名称的显示来源，不提交给 API。人工重建发送组件 ID、类别、原始名称、框坐标，以及可选服务端 `refinement_id`；不接受客户端伪造的掩码。后端识别来源、分数、组件 ID、GLB 节点与 JSON 原始值不因语言切换而修改。导出文件可用于复现与后续编辑，不作为已翻译的完整工程 BOM。

## 开发位置

- `apps/web/src/i18n/messages.ts`：中文原文作 key，每项分别给出英文与西班牙文。占位符如 `{name}`、`{count}` 须在译文中保留。
- `apps/web/src/i18n/index.tsx`：React Provider、翻译函数、已知服务消息映射与系统名称显示。语言代码为 `zh | en | es`，偏好键为 `pv3d.locale`。
- `apps/web/src/components/LanguageSwitcher.tsx`：键盘可操作的语言选择器；选项使用各语言自己的名称。
- 组件使用 `useI18n().t()` 取得固定文案，已知服务提示使用 `localize()`，组件显示名称使用 `componentLabel()`。原始数据不以界面译文替换。

无需外部翻译服务或新增运行依赖。新增文案时补齐两种译文，使用完整句子和参数占位，不拼接可能具有不同语序的句子；之后运行 `make test` 与 `make build`。`App.i18n.test.tsx` 覆盖三语、偏好恢复、运行中切换、错误、编辑、隐藏和名称重建边界；真实浏览器还需检查长文案与窄屏。
