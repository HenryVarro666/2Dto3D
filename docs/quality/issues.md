## E04过程记录（2026-10-31，America/Chicago）

- baseline 0522a85的747个文件已冻结并复制到E04/before；不修改原E03。
- MV-001根因证据：三维NN双向支持低于0.25，但真实主机双向mask重投影/15%深度检查支持为Toyota正↔左0.271、正↔右0.388、SH早期0.561、后期0.464、备前第一台0.403。相邻错配有2D重叠却只有0.009深度支持，故不能仅放宽空间距离。
- MV-002根因证据：Toyota RIGHT细线mask的639格均有有限正深度/置信，全图35分位过滤仅保留42；其后重叠分配40、全局尺度体素39。掩码已存在，扩大SAM不能单独修复此损失。
- PV-008词表探针（未修改生产）：增加connector/tray能将SH10RT机底端口转为connector、真实水平槽转为tray；同时新增Toyota邻配电盒像tray、SH下方电池小件像connector、整排端口像tray等误检，必须加入形状/设备上下文及保护回归。
- Ruling：新增connector/cable_tray两类，更新三语和导出，不把电器件藏到unknown后仍当支架或柜体。代价是词表变化会影响所有DINO分数，必须额外跑原13图保护集。
- Ruling：本轮保持VGGT336、SAM tiny和固定checkpoint；先隔离后处理收益，不把模型换大与代码修复混报。局部低置信点仍属模型估计，不新增/插值几何。

- 回归RED/GREEN：主机深度偏差、亚像素线、全局体素分别复现2→1组、0→7个有效线点和2→3个近邻点的期望差异；分类/新契约初始共11项失败，修复后通过。几何保留测试不补造点。
- 补充投影保护测试先失败（无置信目标仍被合并），随后要求目标深度/置信为正且点有限，再通过。原同图邻居、传递合并与人工ID测试保持通过。
- 三语测试最初错误地在未打开编辑面板时查找ID；改为真实打开各组件编辑面板核对ID，不修改产品行为来迎合测试。当前完整104后端、60前端、构建、Ruff与diff检查通过。

- 独立整分支复核确认MV-006/PV-009/PV-010三项P2，三条给定反例均先失败；另补留白深度抹去线缆端点的失败回归，共4项RED。修正后28项点云/语义测试及完整108后端＋60前端通过，构建/Ruff通过。9c202d1的22任务轮次已归档为intermediate_9c202d1，不用它冒充最终修复结果。
- Ruling：插接件上下文改为全部有效设备锚点，避免远处设备改变局部输出。代价是邻柜/电池附近的错误connector也可能被保留，必须在最终照片和保护集上单独记录，不能用不合理的全局抑制来隐藏误检。
