# 一期实现验证记录

本地日期：2026-10-30。此记录描述当前原型的运行检查，不是跨设备准确率或性能基准。

## 环境和方法

执行主机为 Apple M4 Pro、24GB 内存，Python 3.12、PyTorch 2.8.0，使用 MPS。NVIDIA RTX 5080 未连接测试。依赖及模型 checkpoint revision 已固定。

自动识别使用真实 Grounding DINO tiny＋SAM 2.1 tiny，未用固定检测结果替代。运行资料为本地两张候选照片，是否同一实物未知；这些照片不在 Git 中，也不作为独立领域评测集。

| 下载 | 浏览器下载 GLB，读取后确认四个独立组件节点和 `extras.component_id`。临时爆炸变换不写回原始场景。 |
| 浏览器日志 | 上述流程未观察到浏览器 error／warn。 |

常规 Python 测试存在一条上游 Starlette/httpx 弃用提示，不是测试失败。上述少量时间不报告 p95 或成功率；尚未验证大图、多用户、任意背景、其他设备类别及细小零件。

独立代码审查发现的重建编辑竞态、GLB `world` 节点冲突和推理成功后旧健康错误残留，均先以回归重现再修复。GitHub CI 不下载模型权重；未安装可选 Torch 时，健康恢复的无权重 ML 边界测试会明确跳过，本机安装 ML 依赖后已运行通过。
