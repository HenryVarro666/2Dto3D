- M4 Pro／24GB／MPS：独立直接调用观察到首次交互细化约 12.0 秒（模型载入另约 2.8 秒）、同图加点约 1.3 秒且缓存命中。网页权重已缓存的新进程自动首轮约 24.2 秒、同图多设备重跑约 2.9 秒。均为功能检查的少量观察，运行条件不同，不作时延保证、p95 或跨模型比较。
- small／base-plus／large 仅接入固定 checkpoint 配置，未下载运行；5080、DINO base、SAM 3 未测试。选型与后续评测见 [模型说明](v2/model-options.md)。

## 环境和方法

执行主机为 Apple M4 Pro、24GB 内存，Python 3.12、PyTorch 2.8.0，使用 MPS。NVIDIA RTX 5080 未连接测试。依赖及模型 checkpoint revision 已固定。

自动识别使用真实 Grounding DINO tiny＋SAM 2.1 tiny，未用固定检测结果替代。运行资料为本地两张候选照片，是否同一实物未知；这些照片不在 Git 中，也不作为独立领域评测集。

常规 Python 测试存在一条上游 Starlette/httpx 弃用提示，不是测试失败。上述少量时间不报告 p95 或成功率；尚未验证大图、多用户、任意背景、其他设备类别及细小零件。

独立代码审查发现的重建编辑竞态、GLB `world` 节点冲突和推理成功后旧健康错误残留，均先以回归重现再修复。GitHub CI 不下载模型权重；未安装可选 Torch 时，健康恢复的无权重 ML 边界测试会明确跳过，本机安装 ML 依赖后已运行通过。

进度更新的独立审查补充发现：在区域结果尚未知时误报分割完成，以及新场景的同步 WebGL 错误被父组件结果更新清除。两项均先以失败测试重现再修复；真实查看器在 JSDOM 无 WebGL 时，首次与人工重建分别停在 5／6 与 2／3，不报全部完成。状态文字提高对比度，系统减少动画时停用进度动画。

三语更新的独立审查补充发现：只改类别会影响系统名称翻译，以及重建结果可能丢失显式名称覆盖。两项均先以失败测试重现，再按稳定 ID 与原始名称保留本地名称来源；界面翻译不写入 API 数据。
