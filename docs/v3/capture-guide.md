# V3 拍摄与操作指南

一组照片对应**同一台、同一状态的静止设备**。保留单图模式用于快速结构示意；多图模式用于照片可见表面的相对点云。

## 怎么拍

- 先用 3–5 张：正面、左斜约 30°、右斜约 30°，必要时再补侧面／支架近照。接口支持 2–8 张；先从少量清晰照片开始。
- 相邻照片让主体保留约 60–80% 重叠，这是拍摄起点而非系统质量门槛。移动拍摄位置形成视差，单纯在原地转动镜头帮助较小。
- 保持设备、电线和周围物体静止，光照尽量一致，同一焦距，避免超广角和数字变焦。去掉模糊、严重曝光过度或几乎相同的照片。
- 让线缆、安装件在至少两张照片中清晰出现；近照同时带上部分主机或其他可匹配结构，避免只有一段孤立电线。
- 拍到正面并不能证明背部或内部结构存在。反光壳体、纯色面板、重复散热片和细线是困难场景，必要时增加斜视角和近照。

系统拒绝相同文件哈希的重复照片，但**不会可靠地自动验证它们一定是同一设备**。目前的跨视角支持／视差诊断仅提供提示，不能作为几何准确率认证。

## 网页操作

1. 选择“多角度点云”，选一组照片。可在开始前移除单张；已上传的照片组保持顺序，重新选择照片组会创建新工作区。
2. 点击“融合并识别组件”。进度按实际阶段推进，识别阶段显示当前第几张／总张数。首次权重准备与模型加载可能较久。
3. 左侧切换照片，看该视角的框和掩码；右侧是所有视角在共同坐标中的融合点。组件可选中、隐藏、隔离，背景可单独关闭，点大小可调整。
4. 漏检时“添加组件框”拖框；SAM 细化后加绿色保留点、红色排除点，确认区域。SAM 失败可重试或明确“仅用框保存”，它不会决定零件名称。
5. 在当前照片组件列表中编辑名称和类别；同一全局组件的关联标注同步改名／改类别。每条二维观察有自己的 `id`、`asset_id` 和掩码引用；`component_id` 才代表跨照片的同一个物体。
6. 选中一条标注，在“关联到全局组件”选择同一物体已有的组件，或“独立为新组件”纠正错误合并。自动建议避免将同图中的相邻同类物体合为一个；人工仍应核对。
7. 点击“应用校正到点云”。保留原始几何，重新赋予组件归属并融合／导出，生成新结果版本。确认前的草稿不会自动写入结果。
8. 下载 GLB、PLY 和 JSON。GLB 为原生点图元；PLY 含 `component_index`，0 为背景，其余按 JSON 的 `components` 顺序从 1 开始。它们均为相对坐标、Y 向上。

运行中／草稿中禁止切换重建模式或照片，避免把点投到错误视角。语言可以随时切换；两个重建模式打开后保留各自内存中的工作区。刷新网页不会自动恢复整组工作区，已保存的照片／任务仍在本地数据库并可经 API 读取。停止等待不保证后端计算立即取消。

## 怎么理解结果

点云比规则箱体更适合观察不规则可见表面，但细线在默认 336 输入中可能只占一两个像素，后续过滤、遮挡和分割还会丢点。**多拍照片有帮助，不能保证恢复每根电线或它的电气连接。** 更大的 SAM 可能改善边界；被深度模型漏掉的点无法仅靠改掩码找回，需要改善拍摄或几何模型。

“点云待核对”可能因为某些组件没有有效点、几何支持弱或没有自动组件。可查看背景点、细化框、移除误检、关联观察，或者换成更清晰的有重叠照片。零有效点时不导出空壳假模型；几何推理失败时保留照片组供重试。

**本版没有真实尺寸测量。** 点云范围值是模型相对单位，不可当厘米／毫米。后续尺度标定需要已知三维参考长度、可定位的标定板、可靠相机／传感器信息或实测尺寸，并单独评估误差；从一张无参照照片的像素长度直接换算真实尺寸不可行。箱变、变压器与设备归属树见 [路线图](../roadmap.md)。
