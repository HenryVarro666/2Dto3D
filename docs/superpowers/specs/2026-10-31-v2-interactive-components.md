# V2：交互式组件补录与识别范围

用户已要求先发布当前代码为 V1，再实现 V2。V1 已以 `v1.0.0` 固定在 `7ba23c8`，私有 Release 已发布。V2 保持本地、单照片优先、三语界面与结构示意，不训练模型、不恢复真实厚度或隐藏 BOM。

V2 增加两个完整流程：

1. 选择“单设备／多设备”自动识别范围。单设备保留 V1 的一个主柜及附近组件规则；多设备保留去重后的多个受支持箱体与组件。切换范围仅影响下次明确发起的识别，不能清空已有照片、编辑或自动重跑。人工补录不受一个主柜限制。
2. 框选后进入边界细化草稿，自动用 SAM 2 生成预览。用户选择正点（保留物体）／负点（排除背景），可连续补点、撤销最后一点、清空点、重试、取消、使用原框保存。确认后新增或更新对应组件，明确标为人工引导；最后以人工版本重建三维。现有组件也能从编辑器重新进入细化。

草稿保存命名与类别；请求失败、取消、替换照片、快速补点、切换语言均不得把旧响应写入新草稿。只提交用户确认的最新结果。只改名称／类别应保留已有区域及稳定组件 ID。仅用框保存不伪造掩码。

服务端不信任客户端掩码。每次有效分割保存不可变 refinement 记录、提示框与点、PNG 掩码、区域轮廓、模型 ID／revision。人工重建引用 refinement ID，验证照片与 bbox 对应。保存 PNG 以保留线缆的多个不连通区域和孔洞；SVG 轮廓是近似展示。正常任务与细化共用一个有界推理执行器，不能并发争用 GPU 或无限排队。

默认继续使用当前 tiny 模型。支持服务端显式选择固定 revision 的 SAM 2.1 tiny／small／base-plus／large；不在网页中静默下载大模型。模型比较文档区分检测漏检、分割边界、范围过滤与三维推断，官方基准不当作本项目精度或 5080 性能。只用已有 tiny 权重执行本地真实验证，大模型效果待独立标注与硬件实测。

V1 当前网页保留运行。V2 在项目内隔离 worktree 开发，预览使用独立端口和运行目录；通过测试、真实模型流程及独立审查后才更新规范根目录、推 GitHub 并发布 V2。
